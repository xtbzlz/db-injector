# D&B 修改器使用说明（ダンジョン＆ブライド）

## 一、文件组成

| 文件 | 位置 | 说明 |
|---|---|---|
| `Trainer.exe` | `DXCXN\trainer\` | 修改器主程序（独立窗口，MAA 风格深色界面） |
| `tb_bridge.tpm` | 游戏目录 `plugin\` | 插件桥（已自动部署，勿删；游戏加载它实现 TJS 控制） |
| `TbcCli.exe` | `DXCXN\tools\` | 命令行控制台测试工具（可选） |
| `test_ui.ps1` | `DXCXN\trainer\` | 自动化 UI 测试脚本 |

## 二、使用方法

1. **启动游戏**（`game64.exe`），进入游戏（主菜单或存档均可）
2. **启动 Trainer.exe** → 顶栏圆点变绿显示「已连接」，右侧显示 物品/角色 数量
   - 也可直接点 Trainer 顶栏「启动游戏」一键启动
   - 首次连接自动加载注册表：全部物品(569，来自游戏 game.items 数组)/角色/技能/魔法，双语显示「中文（日文）」

### 指令页（主页面，图形化指令拼接）
- **左侧**：13 个指令分组（等级经验 / 六维属性 / 魔法上限 / 物品 / 时间 / 状态异常 / 结婚 / 队伍 / 地图 / 技能 / 男主数据 / 后宫数值 / 性记录）
- **中间**：分组下的具体指令（50+ 条，全部来自收集的指令清单）
- **右侧**：参数表单（角色/物品/技能/魔法 全部为下拉选择，**实时从游戏读取，全量双语显示「中文（日文）」**——物品 金币（小）（金貨（小））/ 角色 索尼娅（ソーニャ）/ 魔法 火焰（ファイア）/ 技能 侦察（偵察）/ 状态 中毒（毒）/ 佣兵 女刀客（ブレイズマン））→ 指令预览（TJS）→ 点「执行」
- **物品发放**：选择目标角色 + 物品 + 数量 → 执行（按数量逐条 insertItem）
- **魔法上限**：选择角色 → 一键把该系 9 个上限全部拉满（[99×9]）

### 控制台页
- 输入任意 TJS 表达式直接执行（与 MTool krkrConsole 同级）
- 完整 TJS 脚本也支持（for/if 等），例如：
  - `game.party.gold = 99999999`
  - `game.chara[2].learnSkill(o.ファイア)`（学魔法）
  - `game.party.insertItem(o.魔法の浮き橋)`（发物品）
  - `game.guest.entry(o.サンドラ)`（加入支援）
  - `o.サンドラ.love.theo = 100`（好感度）
  - `o.サンドラ.strip.theo = "裸"`（立绘状态）
  - `game.chara[5].mmagicMax = [99,99,99,99,99,99,99,99,99]`（魔法上限）
  - `(function(){ for(var i=0;i<5;i++){ game.party.members[0].insertItem(game.items[1]); } return "ok"; })()`（批量发放）

### 维护页
- **启动游戏** / **重新加载注册表** / **清空全员背包**（bag/bagStat/bagMap 重置为空，防格子错乱；执行前先存档）
- 角色 o 键对照表、佣兵名单速查

### 队伍组（出入队）
- **加入主力（可操控，有背包）**：仅 3 位一键入队——主角テオ / 基友マックス / 洁丽尔リーゼル（`game.party.entry(o.xxx)`）
- **移除主力**：下拉限这 3 位
- **加入支援队伍（右侧）**：6 位 GuestObject 一键入队——珀菈丽丝（ポラリス）/珊朵拉（サンドラ）/玛丽亚（マリア）/布鲁（ブルー）/莱纳斯（ライナス）/米蕾蒂（ミレディ）（`game.guest.entry(o.xxx)`，无背包，与佣兵同类系统）
- **加佣兵 / 取消基友特殊地位**：保留
- 注：リム/クレア/弗蕾德莉卡/缪斯/玛露艾特 等可创建角色招募方便，不提供入队指令；`guest.entry` 不查重，重复执行会重复入队

## 三、技术说明

- **原理**：插件桥（`tb_bridge.tpm`）由 krkrz 引擎官方插件机制（V2Link）加载，获得引擎 TJS API 函数表；Trainer 通过命名管道 `\\.\pipe\tbc_bridge` 与插件通信，插件在游戏主线程内执行 TJS 代码并返回结果。与 MTool 的 krkrConsole 架构同级（MTool 是模式扫描，本方案走官方函数表）。
- **双语数据**：插件新增 `LIST` 命令，用 C++ 层 `EnumMembers` 枚举游戏注册表 `o`（1447 项：键=日文标识符，name=汉化版运行时名，id=物品ID），Trainer 据此生成全部下拉，无需手输。
- **执行通道**：表达式模式（`TVPExecuteExpression`，单表达式）与脚本模式（`TVPExecuteScript`，完整 TJS 语法，顶层语句需分号）。
- **游戏文件零修改**：仅新增 `plugin\tb_bridge.tpm` 一个文件；删除该文件即完全还原。
- **存档安全**：修改均为运行时内存/对象修改，读档可恢复；如遇异常重新读档即可。
- **调试**：插件日志在游戏目录 `tbc_bridge.log`；Trainer 崩溃日志在 `trainer\crash.log`。

## 四、注意事项

- 修改器与游戏必须同为运行状态；游戏重启后 Trainer 自动重连。
- 杀软如拦截 `tb_bridge.tpm` / Trainer.exe，请加入白名单（本地工具，无网络行为）。
- 建议修改前先存档。
