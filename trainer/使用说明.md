# D&B 修改器使用说明（ダンジョン＆ブライド）

## 一、文件组成

| 文件 | 位置 | 说明 |
|---|---|---|
| `Trainer.exe` | 任意位置 | **整个修改器只需这一个文件**（配置与插件均内嵌/自动生成） |
| 配置 | `%APPDATA%\DzbTrainer\config.json` | 自动生成（游戏目录/调试开关），删除后下次启动重新引导 |
| `TbcCli.exe` | `DXCXN\tools\` | 命令行控制台测试工具（可选，开发用） |
| `test_ui.ps1` | `DXCXN\trainer\` | 自动化 UI 测试脚本 |

> 单文件分发：复制 `Trainer.exe` 到任何位置双击即可；插件 `tb_bridge.tpm` 会在选择游戏目录后**自动部署**到游戏 `plugin\` 目录，无需手动复制。

## 二、使用方法

### 首次启动
1. 双击 `Trainer.exe`
2. 自动弹出「选择游戏主程序」对话框 → 定位到游戏根目录，选择 `game64.exe` → 点「打开」
3. 修改器自动完成：**部署插件**（`plugin\tb_bridge.tpm`）→ **启动游戏**（若未运行）→ **初始化连接**（顶栏绿点「已连接」+ 右侧显示物品/角色数量）
4. 注册表自动加载：全部物品(569)/角色/技能/魔法，双语显示「中文（日文）」

### 使用途中
- **换游戏目录**：维护页 →「修改游戏目录」→ 重新选择 → 自动重新执行上述初始化流程
- **启动游戏**：顶栏或维护页「启动游戏」一键启动（使用已配置目录）
- 游戏未运行/已关闭时，顶栏显示「未连接」；游戏启动后自动重连

### 调试模式（运行时开启，无需重新打包）
- 维护页 →「调试模式」开关 → 开/关（持久化到配置）
- 开启后：所有日志**同时写入** `%APPDATA%\DzbTrainer\debug.log`（含时间戳与管道连接明细）
- 维护页 →「查看插件日志」：直接读取游戏目录 `tbc_bridge.log` 显示到日志区
- Trainer 崩溃日志：`trainer\crash.log`

### 指令页（主页面，图形化指令拼接）
- **左侧**：16 个指令分组（等级经验 / 六维属性 / 魔法上限 / 物品 / 时间 / 状态异常 / 结婚 / 队伍 / 地图 / 技能 / 男主数据 / 后宫数值 / 性记录 / 战斗恢复 / 收集 / MOD）
- **中间**：分组下的具体指令（92 条，全部经游戏源码核实）
- **右侧**：参数表单（角色/物品/技能/魔法/地图 全部为下拉选择，**实时从游戏读取，全量双语显示「中文（日文）」**——物品 金币（小）（金貨（小））/ 角色 索尼娅（ソーニャ）/ 魔法 火焰（ファイア）/ 技能 侦察（偵察）/ 状态 中毒（毒）/ 佣兵 女刀客（ブレイズマン）/ 地图 １Ｆ（森の中の廃屋２Ｆ））→ 指令预览（TJS）→ 点「执行」
- **物品发放**：选择目标角色 + 物品 + 数量 → 执行（按数量逐条 insertItem）
- **魔法上限**：选择角色 → 一键把该系 9 个上限全部拉满（[99×9]）
- **战斗恢复**：全回复（官方 recovery）/ 全员全回复 / 回满魔法 / 经验恰好绿字 / 战斗中设置本次经验与金钱奖励
- **收集**：全物品图鉴 / 全怪物图鉴 / 全奖杯达成（30 座奖杯条件一次写齐）/ 一键完成全部已接任务（只改状态不补发报酬）/ 开启游戏内调试功能（underDevelopment 热键）
- **MOD**：汉化包内置 ttmod 开关的快捷控制（13 项 sf.ttmod_*，与游戏内 MOD 菜单等价；标注「需重启」的项改后需重启游戏）
- **地图组**：传送（地图下拉 + 坐标朝向，战斗中拒绝）/ 不遇怪开关（含固定怪）/ 全地图开启+标记已访问 / 遇怪概率（0~1 钳制，无怪地图拒绝）

### 控制台页
- 输入任意 TJS **表达式**直接执行（与 MTool krkrConsole 同级）
- 表达式模式不支持顶层 for/if 等多语句，用 `(function(){ ... })()` 匿名函数包裹即可；多命令可用逗号表达式。例如：
  - `game.party.gold = 99999999`
  - `game.chara[2].learnSkill(o.ファイア)`（学魔法）
  - `game.party.insertItem(o.魔法の浮き橋)`（发物品）
  - `game.guest.entry(o.サンドラ)`（加入支援）
  - `o.サンドラ.love.theo = 100`（好感度）
  - `o.サンドラ.strip.theo = "裸・幸せ"`（立绘状态，值须为该角色 dressInfo 合法键）
  - `game.chara[5].mmagicMax = [99,99,99,99,99,99,99,99,99]`（魔法上限）
  - `(function(){ for(var i=0;i<5;i++){ game.party.members[0].insertItem(game.items[1]); } return "ok"; })()`（批量发放）

### 维护页
- **启动游戏** / **重新加载注册表** / **清空全员背包**（bag/bagStat/bagMap 重置为空，防格子错乱；执行前先存档）
- **修改游戏目录**：重新选择游戏根目录并自动重新初始化
- **调试模式**：运行时开/关调试日志（见上）
- **查看插件日志**：显示游戏目录 `tbc_bridge.log`
- 角色 o 键对照表、佣兵名单速查

### 队伍组（出入队）
- **加入主力（可操控，有背包）**：仅 3 位一键入队——主角テオ / 基友マックス / 洁丽尔リーゼル；自动查重、自动从王立公会摘除归属、战斗中拒绝执行
- **移除主力**：下拉限这 3 位；固定角色（regular）与妻子受保护拒绝移除；战斗中拒绝
- **加入支援队伍（右侧）**：6 位 GuestObject 一键入队——珀菈丽丝（ポラリス）/珊朵拉（サンドラ）/玛丽亚（マリア）/布鲁（ブルー）/莱纳斯（ライナス）/米蕾蒂（ミレディ）（`game.guest.entry(o.xxx)`，无背包，与佣兵同类系统；自动查重）
- **加佣兵 / 取消（恢复）基友特殊地位**：regular 标志开关
- 注：リム/クレア/弗蕾德莉卡/缪斯/玛露艾特 等可创建角色招募方便，不提供入队指令

## 三、技术说明

- **原理**：插件桥（`tb_bridge.tpm`）由 krkrz 引擎官方插件机制（V2Link）加载，获得引擎 TJS API 函数表；Trainer 通过命名管道 `\\.\pipe\tbc_bridge` 与插件通信，插件在游戏主线程内执行 TJS 代码并返回结果。与 MTool 的 krkrConsole 架构同级（MTool 是模式扫描，本方案走官方函数表）。
- **双语数据**：插件新增 `LIST` 命令，用 C++ 层 `EnumMembers` 枚举游戏注册表 `o`（1447 项：键=日文标识符，name=汉化版运行时名，id=物品ID），Trainer 据此生成全部下拉，无需手输。
- **执行通道**：表达式模式（`TVPExecuteExpression`，单表达式；多语句用 `(function(){...})()` 包裹）。入站代码自动剥离 BOM 与首尾空白；执行出错时插件日志记录代码原文（截断 200 字符）便于排查。
- **游戏文件零修改**：仅新增 `plugin\tb_bridge.tpm` 一个文件（由 Trainer 自动部署，删除该文件即完全还原）。
- **单文件分发**：插件 `tb_bridge.dll` 内嵌于 Trainer.exe 资源，运行时自动释放为游戏目录 `plugin\tb_bridge.tpm`（内容比对增量更新；游戏运行中文件被占用时部署失败仅告警不阻断，游戏退出后自动重试部署，下次启动即生效）。
- **存档安全**：修改均为运行时内存/对象修改，读档可恢复；如遇异常重新读档即可。注意「收集」组写的是系统标志 `sf`（跨存档持久，存于 datasu.ksd），其中全奖杯会开启二周目功能。
- **调试**：插件日志在游戏目录 `tbc_bridge.log`；Trainer 调试日志 `%APPDATA%\DzbTrainer\debug.log`（调试模式开启后写入）；崩溃日志 `trainer\crash.log`。

## 四、注意事项

- 修改器与游戏必须同为运行状态；游戏重启后 Trainer 自动重连。
- 杀软如拦截 `tb_bridge.tpm` / Trainer.exe，请加入白名单（本地工具，无网络行为）。
- 建议修改前先存档。
